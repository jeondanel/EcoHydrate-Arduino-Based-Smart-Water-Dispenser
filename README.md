# EcoHydrate-Arduino-Based-Smart-Water-Dispenser
This project is an Arduino-based smart water dispenser with a sustainability-focused system, designed to encourage the use of reusable plastic bottles while reducing single-use plastic waste. The system uses a “bottle-as-a-coin” mechanism, where users insert bottles to gain water refill time, promoting recycling and responsible water consumption. EcoHydrate provides an innovative and eco-friendly solution that combines accessibility, convenience, and environmental awareness.

## Features

- Bottle detection system for validating inserted bottles
- Automated water dispensing mechanism
- Timed water release (15 seconds per valid bottle)
- Bottle-based credit system for water access
- Refillable water dispensing for reusable bottles
- Sensor-based input detection and system activation
- Arduino-controlled dispenser operations
- Multi-bottle input for extended refill time
- User-friendly dispensing interface
- Real-time system response for efficient water access

## Tech Stack
- **Hardware**:
  - Arduino Uno for system control and automation
  - Liquid Crystal Display (LCD) for displaying instructions and system status
  - Capacitive Sensor for bottle detection and validation
  - Ultrasonic Sensor for detecting bottle placement and distance
  - Infrared Sensor for presence detection and triggering
  - Servo Motor for controlling water dispensing
- **Software**:
  - Arduino IDE for programming and uploading the system logic
  - C# for system integration and interface development
- **System Functions**:
  - Sensor-based bottle validation
  - Automated timed water dispensing
  - Real-time user feedback via LCD
  - Reusable bottle tracking and refill management
